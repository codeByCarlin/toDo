# To-Do List (Spring Boot)

Projeto simples de lista de tarefas desenvolvido para praticar os fundamentos de **Spring Boot** e integração com uma interface web.

## Funcionalidades
- Listar tarefas
- Criar nova tarefa (título e descrição opcional)
- Editar tarefa
- Marcar/desmarcar como concluída
- Remover tarefa
- Filtrar por status (*Todas*, *Pendentes*, *Concluídas*) e buscar por título no front

## Tecnologias
- Java + Spring Boot
- HTML, CSS e JavaScript (no front em `index.html`)

## Como rodar o projeto

### 1. Backend (Spring)
Rode a aplicação Spring Boot (por padrão em `http://localhost:8080`).

### 2. Frontend
Abra o arquivo `index.html` no navegador (de preferência usando **Live Server** no VS Code) com a API rodando.
